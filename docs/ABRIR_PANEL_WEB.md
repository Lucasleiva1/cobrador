# Abrir el panel web

El panel no tiene servidor de datos: abre el CSV que la app guardó en Google Drive.

1. En PowerShell, entre en `web-dashboard`.
2. Ejecute `npm.cmd install` una sola vez.
3. Ejecute `npm.cmd run dev`.
4. Abra `http://localhost:3000`.
5. Pulse **Abrir archivo de Drive**.
6. Elija el archivo de la fecha deseada.

Use **Guardar PDF** para abrir el diálogo de impresión del navegador y seleccione **Guardar como PDF**.
