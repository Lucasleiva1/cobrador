# Probar en el emulador

1. Abra `android-app` con Android Studio.
2. En **Tools → Device Manager**, pulse **+ → Create Virtual Device**.
3. Elija **Phone → Pixel 6** y pulse **Next**.
4. Descargue una imagen estable con **Google APIs**, API 36 o 37.
5. Termine el asistente y pulse el triángulo para encender el teléfono virtual.
6. En la barra superior de Android Studio, seleccione ese Pixel y pulse **Run ▶**.

Para probar el respaldo, inicie sesión en Google Drive dentro del emulador. Para probar solamente los cobros no necesita internet ni cuenta.

Prueba rápida recomendada:

1. Escriba precio `50000`.
2. Pulse **Ir a cobrar**.
3. Escriba recibido `60000`.
4. Compruebe que el vuelto muestre `$10.000`.
5. Pulse **Cobrar** y luego **Nueva venta**.
6. Revise la venta en **Hoy**.
7. Cambie a modo **Rápido** desde Ajustes y repita.
